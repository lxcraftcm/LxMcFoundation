## 1. 项目目标

LxMcFoundation 为多个 lxcraftcm Bukkit 插件提供稳定、无业务语义的基础能力。
公共 API 必须至少有两个实际使用方，不得为猜测的未来需求提前引入业务抽象。

## 2. 开发约束

1. 核心模块不依赖 Bukkit 类型。
2. Bukkit 模块只负责适配，不判断具体业务。
3. 异步线程只处理不可变快照和阻塞 I/O。
4. 所有公开 API 必须保持 Java 8 字节码兼容。
5. 不在公共 JAR 内放置业务插件资源或 Bukkit 插件元数据。
6. 类、方法和方法体注释沿用当前插件项目开发规范。

## 3. 模块边界

| 模块 | 职责 | 禁止内容 |
| --- | --- | --- |
| foundation-core | 缓存、持久化、数据生命周期、配置与 i18n 协议 | Bukkit API 和具体业务 |
| foundation-bukkit | Bukkit 配置、语言、颜色和消息适配 | 命令、监听器和业务鉴权 |

## 4. 当前公共能力

1. `CacheStore` 与进程内存实现。
2. `PersistedRecord`、`EntityPersistence` 与 JSON 文件适配器。
3. 按实体键阻断过期修订的单线程异步写后队列。
4. 初始化、正常、持久化降级、失败和关闭数据生命周期。
5. 平台无关配置视图和不可变 Settings 装配边界。
6. 可由每个插件实现消息枚举的 i18n 协议与 Bukkit YAML 适配。
