# LxMcFoundation 公共 API 与版本规范

> 文档编号：1
>
> 最后更新：2026-08-13

## 1. 进入公共库的条件

1. 能力已经有至少两个真实业务插件使用。
2. 类名、方法和日志不包含某个业务插件的专属语义。
3. 公共库能以构造参数或端口获得线程名、日志、配置和平台能力。
4. 不要求两个插件共享静态可变状态、数据目录或同一持久化队列。
5. 公共行为可在不启动 Minecraft 服务端的情况下用 JUnit 验证。

## 2. 公共 API 设计

1. 优先发布小型端口、不可变值对象和显式生命周期。
2. 不把某个插件的 Settings 字段集合放入公共库，公共库只提供 `ConfigView`。
3. 不把业务消息键放入公共库，每个插件通过 `MessageDefinition` 声明自己的枚举。
4. Bukkit 类型不穿透到 `foundation-core`，平台代码放入 `foundation-bukkit`。
5. 异步 API 必须说明回调所在线程，不隐式调用 Bukkit 世界或玩家 API。

## 3. 版本策略

1. 开发阶段使用 `0.x.y-SNAPSHOT`。
2. 兼容修复和新增可选 API 增加修订版本。
3. 破坏现有编译或运行契约的变更增加次版本，并先迁移全部使用方。
4. 业务插件必须使用明确版本，不使用 Maven 版本范围。
5. 开发期通过 `mvn clean install` 安装到本机仓库，稳定版发布到 Maven Central。

## 4. 构建与验收

1. 所有模块使用 Java 8 通过编译与测试。
2. `foundation-core` 不包含 `org.bukkit` 引用。
3. 公共库不包含 `plugin.yml`、命令、监听器或 JavaPlugin 子类。
4. 最终业务插件使用 Shade 内置公共库与必需运行时依赖。
5. 服务端不单独安装公共库 JAR。
